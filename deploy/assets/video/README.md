# 면접관 영상 파일 규칙

포맷: MP4 (H.264 + AAC), 1920×1080 · 25fps · 16:9.
**질문 음성은 영상에 포함되어 있어야 합니다.** `assets/audio/voice/` 의 mp3 는
형태없음(오브) 조건 전용이며, 영상 내장 음성과 동일한 녹음입니다.

## 면접관 배정 (전 조건 동일)

| 면접관 | 인물 | 폴더명 | 화면 좌석 | 담당 문항 |
|---|---|---|---|---|
| 면접관 1 | 중년 남자 | `middle_man` | 왼쪽 | 자기소개(intro), 1-1, 1-2 |
| 면접관 2 | 젊은 여자 | `young_woman` | 가운데 | 2-1, 2-2 |
| 면접관 3 | 젊은 남자 | `young_man` | 오른쪽 | 3-1, 3-2 |

Single 조건은 배정된 페르소나 1명이 7문항 전부를 담당합니다.

## 폴더 구조

```
assets/video/<form>/<persona>/<key>.mp4

  form    : human | avatar
  persona : middle_man | young_woman | young_man
  key     : intro · 1-1 · 1-2 · 2-1 · 2-2 · 3-1 · 3-2 · idle
```

`idle.mp4` 는 참가자가 답변하는 동안 반복 재생되는 대기 영상입니다.
**입을 벌리는 구간이 없어야 합니다** — 무음 오디오로 생성한 뒤,
입이 움직이는 구간은 잘라내고 남은 구간만 이어 붙입니다.
(이어 붙일 때 디졸브는 입술이 겹쳐 보이므로 쓰지 말고, 자세가 비슷한
프레임에서 하드컷으로 이으세요.)

## 파일이 없을 때의 동작

한 조건에 필요한 영상이 하나라도 없으면 **그 조건 전체가 자동으로
정지 사진(`assets/persona/<form>_<persona>.jpg`) + mp3 모드로 내려갑니다.**
한 조건 안에서 일부만 영상이면 참가자마다 자극이 달라지기 때문입니다.
영상을 다 채우면 코드 수정 없이 영상 모드로 돌아갑니다.

진행 로그에 `video_mode` / `photo_mode` 로 어느 쪽이 쓰였는지 기록됩니다.

## 구버전 폴더

`Multi/`, `single/` 은 2025-08 버전 영상입니다. 현재 코드는 참조하지 않으며,
새 구조로 전부 교체된 뒤 삭제 예정입니다.
